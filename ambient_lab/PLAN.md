# ambient_lab — план и состояние проекта

Инструмент для создания dark ambient (стиль øneheart / snowfall) без AI-аудио:
весь звук синтезируется детерминированным кодом, человек — центр принятия решений.

## Что уже есть (ветка claude/dark-ambient-music-tool-ggvv41)

- `engine.py` — движок: JSON-спека → MP3/WAV + MIDI. Прошёл адверсариальный QA
  (3 агента, 20 находок — все исправлены: крашы, алиасинг, стерео-дефекты, арка).
- `analyze.py` — «уши» числами: LUFS, спектр, клики, баланс L/R, арка, жанровые вердикты.
- `SPEC.md` — формат спеки + правила жанра. `GLOSSARY.md` — словарь для общения.
- `app.html` — веб-инструмент coldroom (артефакт): пресеты, макро-ручки, слои, реролл.
- `specs/` — 9 треков: cold static, first snow, empty hall, snowlight, after hours,
  sepia, aphelion (4 последних — сочинены воркфлоу композиторы→судьи), northlight, thaw.

Команды:

```
python3 ambient_lab/engine.py specs/x.json out.mp3 --midi out.mid
python3 ambient_lab/analyze.py out.mp3
```

Зависимости: `pip install numpy scipy soundfile pyloudnorm mido`.

## Роадмап

1. **Текстуры v2** — вместо синтетического шума живые записи: Freesound API (CC0):
   дождь, ветер в деревьях, птицы, комнатный тон. Слой `nature` в спеке.
2. **Разбор референсов** — пайплайн: MP3 → Basic Pitch (ноты) + Demucs (стемы) +
  librosa/Essentia (тональность, BPM, аккорды, спектр, LUFS) → «профиль жанра»
  (типовые прогрессии, темпы, спектральные цели) → правила генератора.
  Референсы слушателя: грузить в чат MP3 (не WAV — WAV не пролезает), по 5 штук,
  или работать в локальной сессии с папкой напрямую.
3. **Гайд из туториалов** — транскрипты + кадры видео (ffmpeg) → сжатый гайд жанра.
4. **Петля фидбэка в приложении** — слушатель отмечает в coldroom что не так →
  фидбэк переводится в правки спеки → новая версия. (Позже: свой скилл со стилевыми
  правилами, как gloom-station-scenes.)
5. **Сэмпловые инструменты** — felt piano (Pianobook/Salamander, SFZ через pysfizz)
   вместо синтетических клавиш; пресеты Vital (JSON) для пэдов.
6. **Интеграция в desktop-приложение** (Tauri + Python, как auto-animator):
   свой «FL Studio» с доступом Claude — превью, правки фрагментов, рендер.

## Как продолжить в локальной сессии

1. Запушить эту ветку (нужен GitHub-доступ) ИЛИ восстановить из bundle-файла
   (отправлен в чат): `git fetch dark-ambient-branch.bundle claude/dark-ambient-music-tool-ggvv41:claude/dark-ambient-music-tool-ggvv41`
2. Локально: `git clone` репозитория → `git checkout claude/dark-ambient-music-tool-ggvv41`
   → открыть Claude Code в папке репо → сказать «прочитай ambient_lab/PLAN.md и продолжай».
   Контекст переносится этим файлом; локальная сессия видит папки с референсами,
   может смотреть видео-туториалы (ffmpeg-кадры) и слушать файлы без лимитов загрузки.
