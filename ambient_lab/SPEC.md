# Формат спеки трека (ambient_lab)

Спека — JSON-файл, из которого движок (`engine.py`) детерминированно рендерит трек.
Один и тот же файл + seed = один и тот же звук, бит в бит.

Запуск:

```
python3 ambient_lab/engine.py spec.json out.mp3          # рендер аудио
python3 ambient_lab/engine.py spec.json out.mp3 --midi out.mid   # + MIDI для FL Studio
python3 ambient_lab/analyze.py out.mp3                   # метрики + проверка на жанровые цели
```

## Поля

```jsonc
{
  "title": "название",
  "seed": 7,                  // целое; управляет фазами, хуманизацией, крэклом
  "bpm": 70,                  // жанр: 60..90
  "beats_per_chord": 8,       // сколько долей живёт один аккорд (8 = 2 такта)

  // Прогрессия. Играется по кругу через весь трек.
  // pad     — войсинг аккорда (MIDI), 4-6 нот, open voicing (верх раскинут на октаву)
  // bass    — корень для саб-баса (MIDI, октавы 1-2: 26..41)
  // arp     — ноты для арпа (MIDI, октава 5: 70..84), по возрастанию
  // piano   — ноты для мягких клавиш (опц.; по умолчанию берутся средние ноты pad)
  "chords": [
    { "name": "Cm9",    "pad": [48,55,58,63,67,74], "bass": 36, "arp": [72,74,75,79,82] },
    { "name": "Abmaj7", "pad": [44,51,56,60,67,72], "bass": 32, "arp": [72,75,79,80] }
  ],

  // Аранжировка. Секции идут подряд; аккорды продолжают крутиться сквозь них.
  // bars       — длина секции в тактах
  // layers     — громкость слоёв 0..1 (отсутствующий слой = 0): pad, bass, arp,
  //              piano, lead, hiss, crackle, wind
  // pad_cutoff — частота лоупасса пэда в этой секции (Гц, 600..2200)
  // arp_pattern— "A" (редкий), "B" (основной), "C" (вариация) или свой:
  //              [[доля, индекс_ноты, велосити], ...], доля 0..beats_per_chord,
  //              индекс -1 = верхняя нота
  "sections": [
    { "bars": 8,  "layers": {"pad":1,"bass":0.8,"hiss":0.7,"wind":0.6}, "pad_cutoff": 900 },
    { "bars": 8,  "layers": {"pad":1,"bass":1,"arp":1,"hiss":0.7}, "pad_cutoff": 1300, "arp_pattern": "B" },
    { "bars": 8,  "layers": {"pad":1,"bass":1,"arp":1,"piano":0.8,"lead":0.6,"crackle":0.6}, "pad_cutoff": 1700, "arp_pattern": "C" },
    { "bars": 4,  "layers": {"pad":0.8,"hiss":0.5,"wind":0.5}, "pad_cutoff": 800 }
  ],

  // Клавиши: [[доля, индекс_ноты_piano, велосити], ...] на каждый аккорд
  "piano_pattern": [[0.0, 2, 0.55], [3.0, 1, 0.4], [5.5, 3, 0.45]],

  "lead_mode": "top",         // "top" — верхняя нота pad; "ninth" — вторая сверху

  "fx": {
    "reverb_sec": 9.0,        // T60 хвоста, жанр: 7..12
    "predelay": 0.04,
    "delay_beats": 0.75,      // дилей арпа в долях (0.75 = 3/16)
    "delay_fb": 0.5,          // feedback 0.3..0.6
    "pad_wet": 0.45, "arp_wet": 0.9, "piano_wet": 0.7, "lead_wet": 0.9
  },

  "mix": { "pad": 0.34, "bass": 0.40, "arp": 0.17, "piano": 0.40,
           "lead": 0.18, "hiss": 0.035, "crackle": 0.05, "wind": 0.10 },

  "master": { "target_rms_db": -18.5, "peak_db": -1.2, "fade_in": 4.0, "fade_out": 10.0 }
}
```

## Правила жанра (øneheart / snowfall-стиль) — для композитора

- Минорные тональности либо мажор с минорной окраской. Референс «snowfall»:
  Gm7–Dm7–Fmaj7–B♭maj7, ~85 BPM. Диатонические аккорды, всегда с 7-й, часто с 9-й.
- Войсинг: нижнюю ноту не трогаем, одну-две средних ноты кидаем на октаву вверх —
  аккорд становится «пышным» и неопределённым. Никаких нот, идущих вниз.
- Мелодия/арп — только ноты аккорда (+9-я ступень). Движение медленное, много воздуха.
- Бас — корни аккордов, только одна нота за раз, октавы 1-2.
- Аранжировка — арка: слои входят по одному каждые 8 тактов, пик ~2/3 трека, потом
  распад до пэда с текстурой. Трек 2-4 минуты.
- Верх спектра пустой — его заполняют текстуры (hiss/crackle/wind), не инструменты.
- Не бойся простоты: 4 аккорда по кругу — норма жанра. Интерес создают автоматизация
  (pad_cutoff по секциям), смена паттернов арпа и вход/выход слоёв.
