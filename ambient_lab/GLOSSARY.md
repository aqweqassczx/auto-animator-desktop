# Словарь: как говорить о нашей музыке

Термины — простым языком, привязаны к нашему инструменту (спека → движок).
Хватит, чтобы давать точный фидбэк без теории музыки.

## Ритм и время

- **BPM** — скорость трека, ударов в минуту. Наш жанр: 60–90. В спеке: `bpm`.
- **Доля (beat)** — один «удар» этой скорости. Четыре доли = **такт (bar)**.
- **Секция** — кусок трека из нескольких тактов, где звучит определённый набор слоёв.
  В спеке: `sections`. Трек = цепочка секций.
- **Арка** — как громкость/плотность растёт и спадает по секциям: тихое вступление →
  слои входят по одному → пик на ~2/3 трека → распад. Это главный источник «движения».
- **Паттерн** — ритмический рисунок: на каких долях сыграть какие ноты. У нас: `arp_pattern`
  (A — редкий, B — основной, C — вариация) и `piano_pattern`.

## Ноты и аккорды

- **Нота / MIDI-номер** — высота звука числом: 60 = «до» первой октавы (C4). +12 = октава вверх.
- **Октава** — та же нота, но вдвое выше/ниже. C3 → C4 → C5.
- **Тональность** — «семья» нот, из которых собран трек, например C minor (до минор).
  **Минор** звучит грустно — наш жанр почти всегда минорный.
- **Аккорд** — 3+ нот одновременно. **Корень (root)** — главная нота аккорда, её играет бас.
- **Септима (7-я) и нона (9-я)** — добавочные ноты, делающие аккорд «задумчивым» вместо
  простого. Cm9 = до-минорный аккорд с ноной. Наш жанр без них не живёт.
- **Войсинг** — как раскидать ноты аккорда по октавам. Наш приём (open voicing): низ не
  трогаем, пару средних нот кидаем на октаву вверх — аккорд становится «пышным».
- **Прогрессия** — последовательность аккордов по кругу (у нас обычно 4). В спеке: `chords`.
- **Арпеджио (арп)** — ноты аккорда, сыгранные по одной, а не разом.

## Слои нашего трека (спека: `layers` внутри секции)

- **Пэд (pad)** — фоновая «подушка»: длинные аккорды, мягкая, размытая. Основа жанра.
- **Саб-бас (bass)** — очень низкая одиночная нота (корень аккорда), скорее ощущается телом.
  **Глайд** — плавное «переползание» с ноты на ноту.
- **Арп (arp)** — звенящая синусовая мелодия по нотам аккорда, уходящая в эхо.
- **Клавиши (piano)** — мягкие редкие «капли» пианино.
- **Лид (lead)** — «поющий» верхний голос с лёгким расстроем и вибрато — та самая «боль».
- **Текстуры** — немузыкальные звуки, заполняющие фон и верх спектра:
  **hiss** = плёночный шум (тот «шелест», который тебе не зашёл), **crackle** = винильные
  щелчки, **wind** = низкий гул ветра. Сюда же пойдут живые записи природы (птицы, дождь).

## Обработка звука (спека: `fx`)

- **Фильтр / cutoff** — «яркость»: срезает верх звука. Меньше cutoff = темнее, глуше.
  У пэда меняется по секциям (`pad_cutoff`) — трек «раскрывается» к пику.
- **Реверб** — эхо помещения; наш — огромный «зал» с хвостом 8–12 секунд (`reverb_sec`).
  **Хвост** — как долго звук дозвучивает. **Predelay** — пауза до начала эха.
- **Дилей** — повторы звука («эхо-эхо-эхо»). **Feedback** — сколько повторов.
  **Пинг-понг** — повторы прыгают лево-право. Фирменный приём жанра на арпе.
- **Автоматизация** — плавное изменение параметра во времени (громкость, cutoff).

## Громкость и микс

- **Микс** — баланс громкостей слоёв (`mix`). «Арп слишком громкий» — это про микс.
- **RMS / LUFS** — средняя/воспринимаемая громкость трека. Наш жанр тихий: −14…−20 LUFS.
- **Пик / клиппинг** — самый громкий момент / перегруз (хрип). Клиппинга быть не должно.
- **Спектр** — раскладка звука по частотам: саб (20–80 Гц) → низ → середина → верх → air.
  «Верх пустой» = нет высоких частот; в жанре их дают текстуры.
- **Стерео / моно** — ширина картинки. Совместимость с моно важна: телефон играет в моно.

## Наши слова

- **Спека** — JSON-описание трека целиком: тональность, аккорды, секции, слои, эффекты.
  Человек правит спеку (или крутит ручки) — движок исполняет. Всегда одинаково (см. seed).
- **Seed** — число-зерно случайности: тот же seed = тот же трек бит в бит.
- **Реролл** — пересобрать паттерны заново с новым seed.
- **Движок** — `engine.py`: спека → MP3/WAV + MIDI. **Анализатор** — `analyze.py`: проверка
  громкости/спектра/стерео числами вместо ушей.

## Как давать фидбэк (примеры)

«пэд темнее», «арп тише и реже», «хвост реверба длиннее», «бас жирнее», «клавиши раньше»,
«пик арки позже», «секции длиннее», «лид убрать», «текстуры заменить дождём» — этого достаточно,
я переведу в правки спеки/движка.
