Как пользоваться
  1. Перед сменой аккаунта: выбери папку текущего аккаунта (обычно верхняя, свежая) → отметь нужные сессии → «Сделать снимок». Это резервная копия.
  2. Переключи аккаунт в Claude Desktop. Если папки нового аккаунта нет в списке «Куда», открой вкладку Code и создай одну любую сессию, потом нажми ⟳.
  3. Закрой Claude кнопкой сверху. В «Откуда» выбери старую папку или снимок, в «Куда» — папку нового аккаунта, нажми «Перенести».
  4. Запусти Claude. Сессии появятся в сайдбаре, история подтянется из ~/.claude/projects.

Перед каждой записью папка назначения автоматически архивируется в backups/.
