# Claude Session Transfer

Локальная программа для переноса сессий Claude Desktop (вкладка Code) между аккаунтами.

## Как устроено

- Список сессий Desktop хранится отдельно для каждого аккаунта: `%APPDATA%\Claude\claude-code-sessions\<account>\<org>\*.json`
  (для версии из Microsoft Store: `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\...`).
- История переписки лежит в `%USERPROFILE%\.claude\projects\<папка>\<uuid>.jsonl` и общая для всех аккаунтов.
- Программа копирует только json-метаданные сессий в папку другого аккаунта. Переносятся ровно те сессии, которые были в сайдбаре, без мусора от субагентов и старых jsonl.

## Запуск

Двойной клик по `start.bat` (нужен Python 3.9+, никаких pip install). Откроется `http://127.0.0.1:8765`.

## Порядок работы

1. На текущем аккаунте выбери его папку, отметь сессии, нажми «Сделать снимок» (резервная копия в `snapshots/`).
2. Переключи аккаунт в Claude Desktop. Если папки нового аккаунта нет в «Куда», создай в Code одну любую сессию и нажми ⟳.
3. Нажми «Закрыть Claude», выбери «Откуда» (старая папка или снимок) и «Куда» (новый аккаунт), нажми «Перенести».
4. Нажми «Запустить Claude».

Перед каждой записью папка назначения архивируется в `backups/`. Кнопка «Подписать» даёт папке понятное имя («Max», «Pro»).
Если что-то не находится или сессии не появились, нажми «Диагностика» → «Копировать» и отправь текст Клоду.
